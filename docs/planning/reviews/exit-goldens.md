# Review: the exit-criteria goldens

The goldens of the exit criteria and of the translate, rotate and mirror transforms, which you have not reviewed yet. The plan (§12 of the first plan, §6 M13 H13 of the second) asks you to read them: each one is what gEdit's own code made of a synthetic input, checked by hand against its criterion, and it stays marked unreviewed until you say it is right. Every program is synthetic, written for gEdit; none is a machine program or one of yours.

How to work through it:

1. Take a row. Open the input named in the row's group and its golden side by side (for the saved programs a diff is enough: `git diff --no-index <input> <golden>` in a terminal). **Do not open the exit programs in an editor** that rewrites bytes: they hold a BOM, CRLF, NUL bytes and Windows-1252 bytes on purpose.
2. Read what the row says it proves, then read the golden for that and nothing else. A golden is right when the machine words, the numbers and the lines it shows are what you, as the NC programmer, expect from that operation.
3. Tick the box when it is right. When it is wrong, write a few words beside the row and leave the box empty.
4. The READMEs say how each group was made: [exit/README.md](../../../tests/fixtures/exit/README.md), [exit2/README.md](../../../tests/fixtures/exit2/README.md) and the geometry goldens in [scripts/README.md](../../../tests/fixtures/scripts/README.md) and [translate/README.md](../../../tests/fixtures/scripts/translate/README.md). Ticking a box does not change a golden or a program by itself.

Counts are in the table at the end of this page. Row groups: 1 the three Phase 1 programs, 2 the Phase 2 criteria X1 to X12 and 3 the arithmetic golden of P4a, 4 translate, 5 rotate, 6 mirror.
